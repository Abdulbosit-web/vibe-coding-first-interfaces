# Система 2. Сайт из карточки на Яндекс Картах или 2ГИС

За вечер собирается одностраничный сайт для кофейни, салона или мастерской: первый экран с кнопкой «Позвонить», меню или услуги с ценами, отзывы, часы работы и адрес, кнопки «Как добраться» и «Написать в Telegram». Внизу экрана телефона закреплена панель быстрых действий.

`index.html` в этой папке — демо на вымышленных данных. Откройте его, чтобы посмотреть, как выглядит сайт.

## Как сделать сайт для своей точки

Действуйте с согласия владельца точки.

1. Откройте `данные.txt` и замените демо-данные на настоящие из карточки на картах: название, адрес, часы, телефон, меню или услуги с ценами, 3–5 отзывов. Удалите строку `демо: да`.
2. Положите 1–7 фото в папку `фото`. Первое станет фоном первого экрана. Берите свои фото или фото владельца.
3. Соберите сайт:
   ```bash
   cd 02-site-from-map-card
   python build.py
   ```
4. Откройте `index.html` в браузере. Чтобы посмотреть версию для телефона, нажмите F12 и включите значок телефона.

Сайт показывает **только то, что написано в `данные.txt`**. Если удалить раздел, пропадёт и блок на сайте. Отзывы копируйте дословно. Подпись под ними («отзыв с Яндекс Карт» или «отзыв из 2ГИС») задаётся строкой `подпись отзыва`.

Внешние библиотеки не нужны: хватает обычного Python. Результат — один файл `index.html` и папка `фото`, без сборщиков.

## Как выложить в интернет бесплатно

**Netlify, самый простой вариант:** зайдите на app.netlify.com/drop и перетащите туда папку `02-site-from-map-card` вместе с `index.html` и `фото`. Сразу получите ссылку.

**GitHub Pages:** создайте репозиторий, загрузите в него `index.html` и папку `фото`, затем откройте Settings → Pages → Deploy from branch → `main`.

**Свой домен:** купите его у регистратора (например, REG.RU или RU-CENTER). В Netlify откройте Domain settings → Add domain и сделайте у регистратора DNS-записи, которые покажет Netlify.

## Как проверить

Откройте сайт по ссылке с телефона и убедитесь, что:
- [ ] «Позвонить» набирает номер;
- [ ] «Как добраться» открывает карточку на картах;
- [ ] «Написать в Telegram» открывает чат;
- [ ] страница не уезжает вбок, текст читается без увеличения;
- [ ] на странице нет ничего, чего не было бы в карточке.

Проверка генератора: `python -m pip install pytest && python -m pytest tests`.

## Если продаёте как услугу

- Попросите у владельца согласие и его фото.
- Не выдумывайте цены, акции и отзывы. Если чего-то нет в карточке, этого не должно быть на сайте.
- Покажите демо со своего ноутбука: так владелец сразу видит результат на данных своей точки.
