# Система 4. Утренняя сводка в Telegram

Каждый день в 8:00 вам приходит одно сообщение: сначала встречи на сегодня, потом важные письма. Остальные письма считаются одной строкой: «И ещё N писем».

```
☀️ Доброе утро! 26 ноября, четверг

📅 Встречи сегодня
• весь день — День рождения Анны
• 09:00–09:15 — Еженедельная планёрка
• 10:00–11:00 — Встреча с поставщиком · Офис

✉️ Важные письма
• Бухгалтерия: Акт сверки за ноябрь
• Банк: Счёт №15 на оплату
И ещё 12 писем.
```

**Почта только читается.** Папка открывается в режиме «только чтение», письма не помечаются прочитанными. Программа ничего не удаляет, не перемещает и никому не отвечает. Это проверяет тест `test_fetch_mails_is_read_only`.

## Что подготовить

1. **Пароль приложения для почты** (обычный пароль не подойдёт):
   - Яндекс: id.yandex.ru → Безопасность → Пароли приложений → «Почта». IMAP включается в настройках почты, раздел «Почтовые программы».
   - Mail.ru: Настройки → Безопасность → Пароли для внешних приложений.
   - Gmail: включите двухэтапную аутентификацию, затем откройте myaccount.google.com/apppasswords.
2. **Ссылка на календарь в формате ICS:**
   - Google Календарь: настройки календаря → «Секретный адрес в формате iCal».
   - Яндекс Календарь: настройки календаря → «Экспорт» → ссылка.
3. **Бот:** в @BotFather отправьте `/newbot` и скопируйте токен. Потом **откройте своего бота и нажмите «Старт»**, иначе он не сможет вам написать.
4. **Ваш Telegram ID:** напишите боту @userinfobot, он ответит числом.

## Установка

Нужен Python 3.10 или новее (python.org/downloads).

```bash
cd 04-morning-digest
python -m pip install -r requirements.txt
cp .env.example .env          # в Windows: copy .env.example .env
```

Откройте `.env` в блокноте и заполните его.

## Запуск

```bash
python digest.py --test-telegram   # бот пишет «на связи»: значит, Telegram настроен
python digest.py --dry-run         # сводка печатается в консоли, в Telegram ничего не уходит
python digest.py                   # настоящая отправка в Telegram
```

## Ежедневно в 8:00

```bash
python schedule.py on              # включить (Windows, macOS, Linux)
python schedule.py on --time 7:30  # выбрать другое время
python schedule.py status          # проверить, включено ли
python schedule.py off             # выключить
```

- Windows: задача `MorningDigest` появится в «Планировщике заданий».
- macOS: через launchd. Если в 8:00 Mac спал, сводка придёт сразу, как он проснётся.
- Linux: через cron.

**Компьютер в 8:00 должен быть включён.** Чтобы сводка приходила всегда, запускайте её на недорогом сервере (VPS) теми же командами.

## Если не работает

Если почта или календарь не ответили, сводка всё равно придёт, а внизу будет блок «⚠️ Не получилось» с причиной.

| Что видите | Что делать |
|---|---|
| `почта: не пускает` | Нужен пароль приложения, а не обычный. Проверьте, что IMAP включён |
| `Telegram не принял сообщение: chat not found` | Откройте своего бота и нажмите «Старт». Проверьте TELEGRAM_CHAT_ID |
| `календарь: HTTP Error 404` | Ссылка ICS устарела. Скопируйте её заново |
| Неправильное время встреч | Проверьте `TIMEZONE` в `.env` (например, `Asia/Tashkent`) |

Если ошибка непонятная, скопируйте её Claude и напишите: «Объясни простыми словами и исправь».


Тесты используют выдуманные письма и календарь. Настоящая почта для них не нужна.
