# Система 1. Telegram-бот, который записывает клиентов

Клиент пишет боту в любое время. Дальше по шагам: **услуга → день → свободное время → имя → телефон**. Сразу после записи вам приходит уведомление.

| Кто | Что умеет |
|---|---|
| Клиент | `/start` — записаться. `/moi` — посмотреть свои записи и отменить. За сутки до визита бот напоминает о записи, отменить можно кнопкой |
| Вы | Уведомление о каждой записи и отмене. `/zapisi` — записи на сегодня и завтра. `/id` — узнать свой Telegram ID |

Записи хранятся в `zapisi.csv`, этот файл открывается в Excel. Отменённая запись остаётся в файле со статусом «отменена», а её окно снова становится свободным.

## 1. Настройте под себя: `config.py`

Откройте файл в любом редакторе. Там можно поменять:
- название бизнеса и часовой пояс;
- **услуги**: название, цену и длительность;
- **график**: часы по дням недели, перерывы, праздники;
- шаг сетки (например, окна каждые 30 минут), на сколько дней вперёд можно записаться, за сколько часов напоминать.

## 2. Установка

Нужен Python 3.10 или новее (python.org/downloads).

```bash
cd 01-booking-bot
python -m pip install -r requirements.txt
cp .env.example .env          # в Windows: copy .env.example .env
```

Вставьте в `.env` токен от @BotFather (`/newbot`).

## 3. Запуск

```bash
python bot.py
```

1. Откройте своего бота в Telegram, нажмите «Старт» и отправьте `/id`.
2. Впишите полученное число в `.env` как `ADMIN_ID=...`.
3. Перезапустите бота: нажмите Ctrl+C, затем снова `python bot.py`.

## 4. Как проверить

Запишитесь к себе со второго аккаунта (или попросите друга) и проверьте:
- [ ] вам пришло уведомление «🆕 Новая запись»;
- [ ] записанное время пропало из свободных окон;
- [ ] `/zapisi` показывает запись;
- [ ] `/moi` у клиента → «Отменить запись»: вам пришло «❌ Отмена», а окно снова свободно;
- [ ] `zapisi.csv` открывается в Excel.

Проверка кода без Telegram: `python -m pip install pytest && python -m pytest tests`.

## 5. Чтобы бот отвечал круглые сутки: на сервер

Бот работает, только пока запущен. Если закрыть ноутбук, бот перестанет отвечать. Чтобы он работал постоянно, нужен недорогой VPS с Ubuntu. Вот как перенести бота:

```bash
# на сервере
sudo adduser --disabled-password bot
sudo -iu bot
# скопируйте папку 01-booking-bot вместе с .env в /home/bot/
cd 01-booking-bot
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
exit

sudo cp /home/bot/01-booking-bot/booking-bot.service /etc/systemd/system/
sudo systemctl enable --now booking-bot      # запустить и включить автозапуск
sudo systemctl status booking-bot            # проверить
journalctl -u booking-bot -f                 # смотреть логи
```

После сбоя или перезагрузки сервера бот запустится сам.

## Важно

- **Бот не может написать человеку первым.** Клиент сначала должен нажать «Старт». Ссылку `t.me/имя_бота` разместите в профиле, в карточке на картах и на QR-коде у кассы.
- В `zapisi.csv` хранятся имена и телефоны клиентов. Файл уже добавлен в `.gitignore`, не выкладывайте его в интернет.
- Запускайте бота только в одном месте. Если он работает одновременно на ноутбуке и на сервере, Telegram выдаст ошибку `Conflict`.
