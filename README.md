# vibe-coding-first-interfaces
My first frontend interfaces built with vibe coding. Learning, experimenting, and building modern web projects.

## 4 системы для бизнеса

Четыре маленькие готовые системы. Каждая либо экономит часы, либо приносит деньги. Все ключи и пароли хранятся в `.env`, этот файл уже добавлен в `.gitignore`.

| Папка | Что делает | Что нужно |
|---|---|---|
| [`01-booking-bot`](01-booking-bot/) | Telegram-бот записи: услуги, свободные окна по графику, уведомления владельцу, напоминания клиенту, отмена кнопкой, записи в CSV для Excel | Python, токен от @BotFather |
| [`02-site-from-map-card`](02-site-from-map-card/) | Одностраничный сайт из `данные.txt` и папки `фото`: меню и цены, отзывы, часы, «Позвонить», «Как добраться», Telegram | Только Python |
| [`03-ad-variants`](03-ad-variants/) | Промпт для разбора лучшего объявления и 4 гипотез + проверка лимитов Директа, VK и Telegram Ads и рискованных слов | Только Python |
| [`04-morning-digest`](04-morning-digest/) | Утренняя сводка в Telegram: встречи из календаря ICS и важные письма по IMAP (почта только читается), запуск каждый день в 8:00 | Python, пароль приложения для почты, токен бота |

У каждой системы свой README: что подготовить, как запустить и как проверить.

**Не делайте всё сразу. Выберите одну систему и доведите её до работающей.**

## Быстрый старт

```bash
cd 04-morning-digest                     # или другая папка
python -m pip install -r requirements.txt   # в 02 и 03 этот шаг не нужен
cp .env.example .env                     # заполните ключи
```

Проверка без настоящих ключей: `python -m pip install pytest`, затем `python -m pytest` в папке системы.

Если что-то пошло не так, скопируйте текст ошибки Claude и напишите: «Объясни простыми словами и исправь».
