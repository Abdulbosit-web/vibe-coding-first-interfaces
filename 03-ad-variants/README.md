# Система 3. Удачная реклама → четыре новых варианта

Возьмите объявление, которое приводит больше всего заявок. Claude разберёт, почему оно работает, и напишет 4 варианта для теста. Каждый вариант проверяет одну гипотезу. Запустите их рядом с удачным объявлением и оставьте лучшее.

## Файлы

| Файл | Зачем |
|---|---|
| `исходные_данные.md` | Шаблон: лучшее объявление, неудачные объявления, цифры, кто клиент |
| `ПРОМПТ.md` | Первое сообщение Claude, готовое к копированию |
| `check_limits.py` | Считает символы по правилам площадки и ищет рискованные слова |
| `варианты.пример.md` | Пример формата. Во втором варианте специально есть «Самый» и «Гарантия»: так видно, как срабатывает проверка |

## Порядок работы

1. Заполните `исходные_данные.md`.
2. Откройте Claude Code в этой папке и отправьте промпт из `ПРОМПТ.md`.
3. Claude сохранит `варианты.md` и сам запустит проверку. Её можно запустить и вручную:
   ```bash
   python check_limits.py варианты.md --platform yandex     # или vk, telegram
   ```
   Внешние библиотеки не нужны, хватает обычного Python.

Пример вывода:
```
Вариант 2
  Заголовок: 43/56 — ок (знаков препинания 0)
  Текст: 59/81 — ок (знаков препинания 2)
  ⚠ рискованные слова: Гарантия, Самый — нужны доказательства или замените
```

## Лимиты, которые зашиты в проверку

| Площадка | Поля |
|---|---|
| Яндекс Директ (текстово-графическое, ЕПК) | Заголовок 56, доп. заголовок 30, текст 81. Слово не длиннее 22–23 символов. Знаки `. , ! : ; "` не входят в лимит, но их не больше 15 |
| VK Реклама | Заголовок 40, текст 90. **Зависит от формата, сверьте в кабинете** |
| Telegram Ads | Текст 160, кнопка 30 |

Лимиты меняются. Если площадка пишет другое, поправьте словарь `LIMITS` в начале `check_limits.py`.

## Как проверить результат

- Запустите 4 варианта рядом со старым объявлением с одинаковым бюджетом.
- Через несколько дней сравните **цену заявки**, а не клики.
- Победителя снова отдайте Claude как «лучшее объявление» и повторите цикл.

## Важно

Реклама в России маркируется. В кабинетах Яндекс Директа и VK Рекламы маркировку делает сама площадка при запуске. Для постов у блогеров её оформляют отдельно, через оператора рекламных данных.

Проверка кода: `python -m pip install pytest && python -m pytest tests`.
