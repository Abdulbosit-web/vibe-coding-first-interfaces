# Промпт для Claude

Откройте Claude Code в этой папке, заполните `исходные_данные.md` и отправьте:

```
Мои данные — в файле исходные_данные.md.

1. Разбери, почему лучшее объявление работает: какую боль оно закрывает, что обещает, какие слова и цифры цепляют. Сравни с теми, что не сработали. Коротко, по пунктам. Сравнивай цену заявки, а не клики.
2. Напиши 4 новых варианта. Каждый проверяет одну гипотезу и меняет одно: другой заход в заголовке, другую боль, другое доказательство или другой призыв. Остальное оставь как у лучшего, чтобы было понятно, что именно сработало.
3. Соблюдай лимиты площадки [Яндекс Директ / VK Реклама / Telegram Ads].
4. Не обещай того, что я не могу выполнить. Никаких превосходных степеней без доказательств («лучший», «№1», «самый», «гарантия»). Цифры бери только из моих данных.

Сохрани в варианты.md строго в таком формате (по нему работает проверка):

## Разбор
- ...

## Вариант 1
Гипотеза: ...
Заголовок: ...
Доп. заголовок: ...
Текст: ...

Для Telegram Ads вместо заголовков используй поля «Текст:» и «Кнопка:».

Потом запусти python check_limits.py варианты.md --platform [yandex / vk / telegram].
Если что-то не влезает или есть рискованные слова, исправь и проверь снова. Покажи итоговую таблицу.
```
